# Creator Rail — حمایت روشن و ساده

نمونهٔ محلی Python/Web برای یک صفحهٔ حمایت فارسی و انگلیسی. در حالت پیش‌فرض **تمام پرداخت‌ها نمایشی و ساختگی هستند**. شبکه یا ولت واقعی در این حالت استفاده نمی‌شود؛ آدرس‌های QR متعلق به کاربر نیستند و نباید به آن‌ها پول فرستاد.

هدف معماری: دریافت مستقیم سازنده و سپردن فاکتور و تأیید پرداخت به BTCPay. در این نسخه، آداپتور با قرارداد رسمی API و پاسخ‌های mock آزموده می‌شود. اتصال به هستهٔ واقعی و Bitcoin Core هنوز از این آزمون‌ها اثبات نمی‌شود. تنظیم mainnet رد می‌شود.

## اجرا

در محیط مجازی Python:

```powershell
python -m pip install -r requirements.txt
python -m uvicorn app:app --host 127.0.0.1 --port 8031
```

صفحهٔ http://127.0.0.1:8031/ را باز کن. مبلغ به ساتوشی است؛ یک فاکتور نمایشی بساز و حالت‌هایی مثل پرداخت ناقص، دیرهنگام یا بازگشت به انتظار را امتحان کن. هر حالت با برچسب نمایشی مشخص است. تبدیل ارز یا انتقال پول انجام نمی‌شود.

```powershell
python -m pytest -q
```

راهنمای [اتصال به BTCPay](docs/INTEGRATION.md)، [نتایج](docs/RESULTS.md) و [مرزهای امنیت](docs/SECURITY.md) جدا هستند. نصب Docker، اجرای نود، دریافت مستقل بازخورد، میزبانی عمومی و دریافت پول واقعی به معنی انجام‌شدن نیستند؛ تنها بعد از مشاهدهٔ نتیجه ثبت خواهند شد.

این نمونه کلید خصوصی/عبارت بازیابی نمی‌خواهد. کلید API آداپتور فقط سمت سرور است. گزارش CSV صرفاً مشاهدهٔ وضعیت فاکتورهاست و دفتر حسابداری یا گزارش مالیاتی رسمی نیست. داشتن TxID هویت حامی را ثابت نمی‌کند.

کد با کمک هوش مصنوعی تهیه شده؛ سهم BTCPay و محدودیت‌ها صریح‌اند. مجوز کد MIT است، اما مجوز کد جایگزین بررسی شرایط سرویس، اقامت، قانون و مالیات نمی‌شود.
